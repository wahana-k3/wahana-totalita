# Wahana Totalita — Next.js Enterprise Safety & Training Platform

Production-ready Next.js 14 (App Router) platform for **PT. Wahana Totalita Konsultan**, built with TypeScript, TailwindCSS, modular data architecture, and full Static Site Generation (SSG).

> **Current Archive Status:** Locked on Git with `noindex, nofollow` to protect active Hostinger traffic while experimentation is paused.  
> Detailed architecture, page inventories (770+ original pages, 300+ cleaned pages), and re-indexing instructions are documented in [PRODUCTION_ARCHITECTURE_NOTE.md](PRODUCTION_ARCHITECTURE_NOTE.md).

## Quick Start
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build and verify all 1,058 static pages
npm run build

# Run automated deep SEO tags and integrity audit
python scripts/audit_deep_seo_tags.py
```
